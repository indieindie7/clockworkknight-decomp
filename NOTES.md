## Disc layout
- Boot program = `A.BIN` (first file by LBA): ck2usa 387952 bytes (identical to APUS.BIN), fukubukuro 388880, gekan 227486.
  gekan A.BIN begins with an SH-2 prologue (2f e6 ...), so code starts at 0x06003000. ck2usa A.BIN head 00 02 91 15 20 19 ... (same head as JAPUS.BIN 972544) -- check whether it is a header/table before code.
- Level overlays `AREA<n><x>.BIN` (~600-950 KB each, SH-2 prologue at byte 0 in gekan AREA8B.BIN, 296 prologues) = code + data per area; load address unknown yet (find in A.BIN loader).
  ck2usa/fukubukuro prefix the names: J*, G*, B*, Z* (likely Joukan = CK1, Gekan = CK2, Bosses Galore, ?). JAPUS.BIN / A.BIN pair likewise.
- Other: SELECT.BIN / SELTTL.BIN / MOVSEL.BIN (menus), SNDDRV.BIN 45056 (sound driver, 68000), SNDTBLTV.BIN, STAFF.BIN (data, 0xff fill), WMAP*.BIN (world map), *.AVI (Cinepak-style movies), GTITLE.DA/BTITLE.DA, CDDA1.
- gekan `README.DOC` is a Shift-JIS staff message file: it names staff -> never publish it or quote it.
